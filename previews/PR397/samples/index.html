Accessing samples

FlexiChains stores data in a dict-of-array format (a column-oriented form, similar to dataframes). This means that it is very easy to access all the data for a given variable, but accessing all the data for a given sample (i.e., iteration / chain number) is a bit more involved.

Consider our now-familiar example chain:

using FlexiChainschn = FlexiChains.EXAMPLE_CHAIN
╭─FlexiChain (10 iterations, 2 chains) ────────────────────────────────────────╮
│ ↓ iter  = 101:110                                                            │
│ → chain = 1:2                                                                │
│                                                                              │
│ Parameters (3) ── VarName                                                    │
│  Float64          mu, tau                                                    │
│  Vector{Float64}  theta (8,)                                                 │
│                                                                              │
│ Extras (2)                                                                   │
│  Float64  logjoint                                                           │
│  Bool     is_divergent                                                       │
╰──────────────────────────────────────────────────────────────────────────────╯

Here, we have three parameters mu, tau, and theta. FlexiChains makes it very easy to access the value of a single parameter across all iterations and chains:

chn[@vn(mu)]
┌ 10×2 DimArray{Float64, 2} Parameter(mu) ┐
├─────────────────────────────────────────┴─────────────── dims ┐
  ↓ iter Sampled{Int64} 101:110 ForwardOrdered Regular Points,
  → chain Sampled{Int64} 1:2 ForwardOrdered Regular Points
└───────────────────────────────────────────────────────────────┘
   ↓ →   1         2
 101    11.3517    4.78008
 102    11.3517    4.59214
 103    11.3517    5.68752
 104    11.3517    7.10065
   ⋮               
 107     1.30113   5.48149
 108     0.915619  6.2456
 109     0.284842  6.25491
 110     0.516548  1.47832

However, suppose you want to obtain the values of all parameters at a given iteration and chain number. For example, you might want to know what happened at the fifth iteration.

One way is to subset a chain. The issue is that that gives you just another chain back:

subsetted = chn[iter=5, chain=1]
╭─FlexiChain (1 iteration, 1 chain) ───────────────────────────────────────────╮
│ ↓ iter  = 105:105                                                            │
│ → chain = 1:1                                                                │
│                                                                              │
│ Parameters (3) ── VarName                                                    │
│  Float64          mu, tau                                                    │
│  Vector{Float64}  theta (8,)                                                 │
│                                                                              │
│ Extras (2)                                                                   │
│  Float64  logjoint                                                           │
│  Bool     is_divergent                                                       │
╰──────────────────────────────────────────────────────────────────────────────╯

and to access the data you will still need to index into it, which is rather awkward:

(mu=only(subsetted[@vn(mu)]), tau=only(subsetted[@vn(tau)]))
(mu = 11.351650969356333, tau = 0.846032171561763)

We should definitely like to have a better way of accessing this collection of values at a given iteration/chain.

Generally speaking, the operation above can be viewed as a transformation from column-oriented data to row-oriented data, or from a dict-of-arrays to an array-of-dicts. FlexiChains provides a few convenient ways for you to do this transformation.

values_at

The function FlexiChains.values_at is at the core of this transformation. Given iteration and chain indices (as keyword arguments), it returns some container that holds all the values for a given iteration.

draw = FlexiChains.values_at(chn; iter=5, chain=1)
VarNames.Draw
 ├─ parameters
 │  VarNamedTuple
 │  ├─ mu => 11.351650969356333
 │  ├─ tau => 0.846032171561763
 │  └─ theta => [10.492901852254972, 11.46635882152557, 11.570533934319785, 12.130958608708998, 10.967643507906876, 12.011427174304124, 10.793983473375265, 11.581970127184468]
 └─ extras
    ├─ logjoint = -45.082557361617546
    └─ is_divergent = false

There is a subtlety here in that the exact type of the container returned depends on what is stored in the chain.

Structures

For the interested reader, or if you are developing FlexiChains, this is determined by the structures stored in the chain, which are meant to be a 'template' for the container. If you are just a user who has obtained a FlexiChain from some library, should not need to worry about this, as the structures should be set up correctly for you by that library.

For chains that have parameter type VarName, i.e. a VNChain, the returned container should usually be a VarNames.Draw. This is a struct that separately stores the parameters and the stats as a VarNames.VarNamedTuple and a NamedTuple respectively.

Not getting a `Draw`?

If you instead get an OrderedDict, you should probably report this as a bug to the library that produced the chain.

For more information about these types, the reader is referred to the VarNames.jl docs. The key point here is that this is a high-fidelity representation of the data. You can access the parameters and extras separately:

ps = FlexiChains.parameters(draw)
VarNamedTuple
├─ mu => 11.351650969356333
├─ tau => 0.846032171561763
└─ theta => [10.492901852254972, 11.46635882152557, 11.570533934319785, 12.130958608708998, 10.967643507906876, 12.011427174304124, 10.793983473375265, 11.581970127184468]
FlexiChains.extras(draw)
(logjoint = -45.082557361617546, is_divergent = false)

The parameter VarNamedTuple can be further indexed into with VarNames to obtain the values of individual parameters. Much like a FlexiChain itself, you have the ability to index into a VarNamedTuple with sub-variables, such as theta[1:3]:

ps[@vn(mu)], ps[@vn(theta[1:3])]
(11.351650969356333, [10.492901852254972, 11.46635882152557, 11.570533934319785])

Choosing a different container type

Sometimes, though, one might want different output formats. There is some support for converting to NamedTuple or AbstractDict, by passing an optional type argument.

Conversion to NamedTuple is not faithful

Note that conversion to NamedTuple is lossy if you have VarNames that contain indexing or field access syntax (e.g., x[1] or x.a).

FlexiChains.values_at(chn, NamedTuple; iter=5, chain=1)
(mu = 11.351650969356333, tau = 0.846032171561763, theta = [10.492901852254972, 11.46635882152557, 11.570533934319785, 12.130958608708998, 10.967643507906876, 12.011427174304124, 10.793983473375265, 11.581970127184468], logjoint = -45.082557361617546, is_divergent = false)
FlexiChains.values_at(chn, Dict; iter=5, chain=1)
Dict{Union{FlexiChains.Extra, FlexiChains.Parameter{var"#s91"}} where var"#s91"<:VarName, Any} with 5 entries:
  Parameter(theta)     => [10.4929, 11.4664, 11.5705, 12.131, 10.9676, 12.0114,…
  Parameter(mu)        => 11.3517
  Extra(:logjoint)     => -45.0826
  Parameter(tau)       => 0.846032
  Extra(:is_divergent) => false

Obtaining only parameters

Often the stats are not of very much interest, and you just want the parameters. In that case, you can use parameters_at:

FlexiChains.parameters_at(chn; iter=5, chain=1)
VarNamedTuple
├─ mu => 11.351650969356333
├─ tau => 0.846032171561763
└─ theta => [10.492901852254972, 11.46635882152557, 11.570533934319785, 12.130958608708998, 10.967643507906876, 12.011427174304124, 10.793983473375265, 11.581970127184468]

This is exactly the same as values_at, except that it only returns the parameters.

Not getting a VarNamedTuple

Just as above, if you instead get an OrderedDict, you should probably report this as a bug to the library that produced the chain.

Drawing random samples

To get a random sample from the chain, you can use Base.rand. The container type returned is the same as for values_at:

rand(chn)
VarNames.Draw
 ├─ parameters
 │  VarNamedTuple
 │  ├─ mu => 1.3011264899259882
 │  ├─ tau => 1.2575762907235706
 │  └─ theta => [-0.2786033669818768, 2.2043452367767897, 1.4986981059499982, 1.250858631869015, 1.2039397973087334, 2.6112913316673687, 1.2156052826241897, 1.2029631872492423]
 └─ extras
    ├─ logjoint = -46.551692964683895
    └─ is_divergent = true

FlexiChains.values_at — Function
FlexiChains.values_at(chn::FlexiChain; iter=:, chain=:)
FlexiChains.values_at(chn::FlexiChain, ::Type{Tout}; iter=:, chain=:)

Extract all values from the chain corresponding to a particular set of MCMC iterations(s).

The iter and chain keyword arguments can be anything used to index into the respective dimensions of a FlexiChain, such as an integer, a vector of integers, a range, or a DimensionalData.jl selector. Both default to : (i.e. all iterations / all chains).

In particular, you can convert the entire chain into a DimMatrix of the desired output type by calling this function with no keyword arguments.

To get only the parameter keys, use FlexiChains.parameters_at.

The output type can be specified with an (optional) positional argument. Possible options are:

  • unspecified: uses the structure stored in the chain to determine the output type. Specifically, for chains sampled with Turing.jl, the stored structure will be VarNamedTuple, and consequently the output of parameters_at will be a DynamicPPL.ParamsWithStats per iteration (which stores the parameters as a VarNamedTuple, and the stats/extras as a NamedTuple).

    For chains that do not have a stored structure, the default output will be an OrderedDict, or NamedTuple for TKey = Symbol.

  • Tout <: AbstractDict: returns a dictionary mapping ParameterOrExtra{TKey} to their values. This is the most faithful representation of the data in the chain.

  • Tout = NamedTuple, or Tout = ComponentArray: attempts to convert every key name to a Symbol, which is used as the field name in the output NamedTuple or ComponentArray.

Using `NamedTuple` or `ComponentArray`

This will throw an error if any key cannot be converted to a Symbol, or if there are duplicate key names after conversion. If you have parameter names that convert to the same Symbol, you can either use OrderedDict, subset the chain before calling this function, or rename your parameters. Furthermore, please be aware that this is a lossy conversion as it does not retain information about whether a key is a parameter or an extra.

For order-sensitive output types, such as OrderedDict, the keys are returned in the same order as they are stored in the FlexiChain. This also corresponds to the order returned by keys(chn).

FlexiChains.parameters_at — Function
FlexiChains.parameters_at(chn::FlexiChain; iter=:, chain=:)
FlexiChains.parameters_at(chn::FlexiChain, ::Type{Tout}; iter=:, chain=:)

Extract all parameter values from the chain corresponding to a particular set of MCMC iteration(s), discarding non-parameter (i.e. Extra) keys.

The iter and chain keyword arguments can be anything used to index into the respective dimensions of a FlexiChain, such as an integer, a vector of integers, a range, or a DimensionalData.jl selector. Both default to : (i.e. all iterations / all chains).

In particular, you can convert the entire chain into a DimMatrix of the desired output type by calling this function with no keyword arguments.

To get all keys (not just parameters), use FlexiChains.values_at.

The output type for each iteration can be specified with the first (optional) positional argument. Possible options are:

  • unspecified: uses the structure stored in the chain to determine the output type. Specifically, for chains sampled with Turing.jl, the stored structure will be VarNamedTuple, and consequently the output of parameters_at will be a VarNamedTuple per iteration.

    For chains that do not have a stored structure, the default output will be a NamedTuple if the key type is Symbol, and an OrderedDict otherwise.

  • Tout <: AbstractDict: returns a dictionary mapping TKey to their values.

  • Tout = NamedTuple or Tout <: ComponentArray: attempts to convert every parameter name to a Symbol, which is used as the field name in the output NamedTuple or ComponentArray.

Using `NamedTuple` or `ComponentArray`

This will throw an error if any key cannot be converted to a Symbol, or if there are duplicate key names after conversion. If you have parameter names that convert to the same Symbol, you can either use OrderedDict, subset the chain before calling this function, or rename your parameters. Furthermore, please be aware that this is a lossy conversion as it does not retain information about whether a key is a parameter or an extra.

For order-sensitive output types, such as OrderedDict, the parameters are returned in the same order as they are stored in the FlexiChain. This also corresponds to the order returned by FlexiChains.parameters(chn).

Base.rand — Function
Base.rand(rng::Random.AbstractRNG, chn::FlexiChain, dims::Int...; parameters_only=false, weights=nothing)

Sample uniformly from a FlexiChain with replacement.

Pass weights::StatsBase.AbstractWeights to sample with probabilities proportional to the weights instead. Supply one weight per sample, with all iterations of the first chain followed by all iterations of the second chain, and so on.

rand([rng,] chn) returns a single sample, whereas rand([rng,] chn, dims...) returns an Array of samples with dimensions dims.... The parameters_only keyword specifies whether the returned samples include only parameters, or both parameters and extras.

In general, the return type of rand is the same as the return type of FlexiChains.parameters_at or FlexiChains.values_at (but wrapped in an Array if dims is not empty). This means that the return type can depend on the 'structure' stored in the FlexiChain.

For example, if chn::FlexiChain{VarName} was constructed using Turing.jl, rand(chn) will return a DynamicPPL.ParamsWithStats, and rand(chn, parameters_only=true) will return a DynamicPPL.VarNamedTuple.
