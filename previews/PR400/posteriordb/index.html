Documentation for PosteriorDB.jl ↗

If you have loaded a PosteriorDB.ReferencePosterior, you can transform it into a FlexiChain{VarName} using FlexiChains.from_posteriordb:

using PosteriorDB, FlexiChains# This is the long way.pdb = PosteriorDB.database()post = PosteriorDB.posterior(pdb, "eight_schools-eight_schools_centered")ref = PosteriorDB.reference_posterior(post)chn = FlexiChains.from_posteriordb(ref)

chn = FlexiChains.from_posteriordb(pdb, "eight_schools-eight_schools_centered")

FlexiChains.from_posteriordb(ref::PosteriorDB.ReferencePosterior)
FlexiChains.from_posteriordb(db::PosteriorDB.PosteriorDatabase, model_name::String)

Load a reference posterior from PosteriorDB.jl into a FlexiChain{VarName}.

PosteriorDB stores vector-valued parameters as separate scalar entries, using Stan's naming convention (e.g. theta[1], ..., theta[8]). When loaded into FlexiChains, these are recombined into a single vector-valued parameter (e.g. @vn(theta), where each draw is a Vector{Float64}).
