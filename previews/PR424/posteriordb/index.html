PosteriorDB.jl

Documentation for PosteriorDB.jl ↗

FlexiChains allows you to load reference posteriors (i.e., chains sampled in Stan) from PosteriorDB.

To see a list of all available reference posteriors, use FlexiChains.available_posteriordb_references:

To load a reference posterior, use FlexiChains.from_posteriordb:

chn = FlexiChains.from_posteriordb("eight_schools-eight_schools_centered")

Load a reference posterior from PosteriorDB.jl into a FlexiChain{VarName}.

The most convenient method to use is the first, which just takes a String. The others technically allow for more flexibility but should be very rarely needed.

PosteriorDB stores vector-valued parameters as separate scalar entries, using Stan's naming convention (e.g. theta[1], ..., theta[8]). When loaded into FlexiChains, these are recombined into a single vector-valued parameter (e.g. @vn(theta), where each draw is a Vector{Float64}).

For models that do not have a reference posterior, an ArgumentError is thrown. You can use FlexiChains.available_posteriordb_references to see which models have reference posteriors.
